# OctoPrint logo

`octoprint-logo.png` is the unmodified original artwork distributed by the
[OctoPrint project](https://github.com/OctoPrint/OctoPrint/blob/dev/src/octoprint/static/img/logo.png).

- Upstream path: `src/octoprint/static/img/logo.png`
- Git blob: `bf5286f423db32bba7556677ed04974c0679cd2b`
- SHA-256: `3d8b79835693e9040fa9beabe46dc733e26982f2ad9dd9f462b8790d0f2070e2`
- Upstream [license and notices](https://github.com/OctoPrint/OctoPrint/blob/dev/LICENSE.txt)

The LCD renderer scales it with Lanczos filtering, composites its transparency
onto the black screen and transmits it using the panel's RGB565 colors. It
does not redraw or replace the artwork with an approximation. The original
image is bundled with the plugin; rendering requires no network access.
